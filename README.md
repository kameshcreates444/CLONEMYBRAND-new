# CLONEMYBRAND — Reel Creation Landing Funnel

Static landing page for KameshCreates reel creation & editing services.

## Files

- `index.html` — the site entry point (served at `/`)
- `reel-creation-landing-funnel v3.html` — original source file, kept for reference

## Deploying on Vercel

1. Go to [vercel.com/new](https://vercel.com/new) and import this repository.
2. Framework Preset: **Other**
3. Build Command: leave empty
4. Output Directory: leave empty (repository root)
5. Deploy.

Vercel serves `index.html` at the root automatically — no build step or `vercel.json` needed.
